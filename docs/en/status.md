# Project Status

> Spanish source: [`../es/estado.md`](../es/estado.md). The Spanish version is canonical; this file mirrors it.

**Last update:** November 2026

## Verified state

- Astro 7.4.1 project with `@astrojs/cloudflare` 14.4.1 and `wrangler` installed. Package manager: bun.
- `astro.config.mjs` registers the `cloudflare()` adapter, internationalization (ADR-004), the brand fonts, and `site` from the `SITE_URL` build variable.
- Implemented in `feature/landing`: base layout with language switcher (`/` in Spanish and `/en` in English), global styles, hero, services and process section, the “A real project” (Katedra, showing its live site in miniature through an iframe) and “What it costs” sections, a language switch that keeps the reading position with a wipe animation, base SEO (titles, Open Graph, `robots.txt`; `canonical` and `hreflang` only if `SITE_URL` is set), and the contact form (component, `POST /api/contact` endpoint, and schema in `supabase/contact_messages.sql`). See [architecture.md](architecture.md).
- `bun run build` passes with and without `SITE_URL`, and with the form (verified on the `feature/landing` branch).
- `bun run check` (`wrangler types` and `astro check`, with TypeScript 6) passes with 0 errors, 0 warnings, and 0 hints (verified on `feature/landing`). `worker-configuration.d.ts` is generated by that command and is not versioned.
- The endpoint was tested in `bun run preview` with fake variables: it returns `400 invalid` for invalid data or a body that is not a form, `400 captcha` for a fake token, and `500 unavailable` without environment variables.
- `wrangler.jsonc` targets Workers with Static Assets (`main` + `assets`).
- `.gitignore` excludes `.wrangler/` and `.dev.vars*`; `.dev.vars.example` and `.env.example` list the variables.
- Verified in the browser (November 2026): `/` and `/en` render every section with no console errors in 390, 768, 820, and 1440 px windows, with no horizontal overflow; the six-link menu fits completely and the wordmark does not overlap the header buttons. Sizes were tested by loading the page in an iframe of that width. `bun run dev` returns 200 on `/` and `/en`.
- Not verified: the contact form in a browser; Safari and Firefox (in Firefox the Katedra miniature uses `transform` instead of `zoom`); the real integration with Turnstile, Supabase, and Resend (credentials are missing); the Supabase REST path and `turnstile.reset()`, not confirmed in the documentation; and the endpoint's 10 ms CPU limit. The Katedra miniature depends on `katedra-client.vercel.app` continuing to allow embedding.
- There is no sitemap, `og:image`, logo, or production domain.
- The actual deployment, per-branch previews, and secrets in Cloudflare are not configured.
